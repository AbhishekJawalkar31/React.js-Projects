# Password Generator

A simple React-based password generator that creates random passwords based on the selected length, numbers, and special characters.

## Features

- Generate random passwords
- Set password length from 6 to 20 characters
- Include numbers
- Include special characters
- Copy generated password to clipboard
- Automatically generate a new password when options are changed

## Technologies Used

- React
- JavaScript
- Tailwind CSS
- CSS
- Vite

## Installation

```bash
npm install
```

## Run the Project

```bash
npm run dev
```

Open the local development URL shown in the terminal.

## Project Functionality

The password is generated using a combination of uppercase and lowercase letters. Numbers and special characters can be added using the available options. The password length can be adjusted using the range slider.

The generated password can be copied to the clipboard using the **Copy** button.
