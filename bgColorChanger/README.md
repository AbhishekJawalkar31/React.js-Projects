# Background Color Changer

A simple React-based background color changer that allows users to change the background color of the screen by selecting different color buttons.

## Features

- Change background color instantly
- Available colors:
  - Red
  - Green
  - Blue
  - Olive
  - Gray
  - Yellow
  - Black
- Smooth background color transition

## Technologies Used

- React
- JavaScript
- Tailwind CSS

## Installation

```bash
npm install
```

## Run the Project

```bash
npm run dev
```

Open the local development URL shown in the terminal.

## Project Functionality

The application uses React's `useState` hook to manage the current background color. Clicking a color button updates the state and changes the background color of the screen accordingly.
