# React.js Projects

A collection of small React applications and learning projects. Each project is self-contained and has its own dependencies and README.

## Projects

| Project | Description |
| --- | --- |
| [Background Color Changer](./bgColorChanger/) | Change the page background using a set of color controls. |
| [Currency Converter](./currencyConverter/) | Convert an amount between currencies, swap selections, and fetch exchange rates. |
| [MiniStore](./mini-store/) | Browse and filter products, view details, and manage a persistent shopping cart with light and dark themes. |
| [Mini Context](./miniContext/) | Learn how React Context shares user state between components. |
| [Password Generator](./password-generator/) | Generate customizable passwords and copy them to the clipboard. |
| [Personal Task Manager](./personalTaskManager/) | Create, search, filter, complete, and remove tasks saved in local storage. |
| [React Router Demo](./reactRouter/) | Explore client-side navigation, shared layouts, and dynamic routes. |
| [Theme Switcher](./themeswitcher/) | Switch between light and dark themes using React Context. |

## Run a project

Open a terminal in the project directory, then install its dependencies and start its development server:

```bash
cd <project-folder>
npm install
npm run dev
```

For project-specific features, scripts, and setup notes, see that project's README.
